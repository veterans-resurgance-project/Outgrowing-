📄 AFTI System Offline Readme & Map

Local documentation guide for managing the project footprint directly from local files or a memory stick.

🚨 THE ANDROID TABLET RULE:
To prevent mobile character truncation or file corruption during edits, NO SINGLE CODE BOX IN THIS PROJECT CAN EXCEED 60 LINES OF CODE. Pack layouts tightly using inline-adjacent CSS parameters.
📂 CORE REPOSITORY ARCHITECTURE:
  • index.html: Master portal hub with universal navigation.
  • shared-harvest-hub.html: Landowner friction mitigation loop tracker.
  • incubator-hub.html: Micro-farm capital calculators & asset shares.
  • cohort-gradebook.html: Dynamic student scorecard & merit badges.
  • gradebook-archive.html: Safe history cloner to protect student logs.
🔄 CACHE BYPASS PROTOCOL:
When linking files or updating modules, append a cache-busting version string (e.g., ?v=15) to the URL. This forces mobile browsers to load your freshest local changes instantly instead of freezing on old memory.
